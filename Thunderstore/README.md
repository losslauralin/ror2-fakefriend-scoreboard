# FakeFriend Scoreboard

Puts [FakeFriend](https://thunderstore.io/c/riskofrain2/p/NotStudio/FakeFriend/)'s AI partners into the vanilla
**Tab scoreboard**, beside the real players, with their items and equipment.

Requires FakeFriend. Client-side UI: no change to difficulty scaling, player count or run logic, and FakeFriend's own
code is untouched — the bot list is read from it while the game runs.

## What you get

One extra scoreboard strip per bot: name, level, money, item icons, equipment icon. Hovering those icons gives you
whatever your other mods already show there — with [LookingGlass](https://thunderstore.io/c/riskofrain2/p/DropPod/LookingGlass/)
installed you get full item descriptions.

## Limits

- A dead bot leaves the list until it respawns.
- Bots set to items mode `None` have no items to show.
- Only players who have this mod see the bot strips. The bots themselves are already synced to everyone by the game.
